# P_Chem_Lab
Materials for Physical Chemistry Lab at Duke University

## To use MatLab online
Go to the online version of MatLab and log in using your duke email address. Then start MatLab Online.  Use Github to clone the files for P-Chem Lab into your MatLab folder, using the instructions below.
In MatLab Online:
* In the HOME tab, choose New > GitClone
* In the URL, put **https://github.com/ProfessorCuprous/P_Chem_Lab/**
* In the Folder, put **/MATLAB Drive/P_Chem_Lab/**
* Press the Clone Button

## To use MatLab installed on your own computer 
Please download all of the files in this folder (and its child folders), including MatLab scripts, LiveScripts, and the example data files. Put these files and folders within your default Matlab folder (on your own computer). We recommend that you create a new folder for this course inside your default MatLab folder or in a place where you can easily find them, and place all the files inside the /MatLab/P_Chem_Lab.
