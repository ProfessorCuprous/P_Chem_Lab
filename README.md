# P_Chem_Lab
Materials for Physical Chemistry Lab at Duke University

## To use MatLab online
Go to the online version of MatLab and log in using your duke email address. Then start MatLab Online.  Use Github to clone the files for P-Chem Lab into your MatLab folder, using the instructions below.
In MatLab Online:
* In the HOME tab, choose New > GitClone
* In the URL, put **https://github.com/ProfessorCuprous/P_Chem_Lab/**
* In the Folder, put **/MATLAB Drive/P_Chem_Lab/**
* Press the Clone Button

## To use MatLab installed on your own computer 
Please download all of the files in this folder (and its child folders), including MatLab scripts, LiveScripts, and the example data files. Put these files and folders within your default Matlab folder (on your own computer). We recommend that you create a new folder for this course inside your default MatLab folder or in a place where you can easily find them, and place all the files inside the /MatLab/P_Chem_Lab.

# Files Used for PChem Labs
## Module 2: MatLab Training Module (CHEM310L + 301L)
* **expt-1.mat** <a binary file containing x and y variables for matlab introduction - HCl data for the matlab orientation exercise>
* **lsq.mlx** <general use script, linear regression least squares analysis>
* **Practice_LiveScript_XXX.mlx** 	<LiveScript file that will help orient you to MatLab and the use of LiveScript files to record your work.>
## Module 3: Error Analysis Module (CHEM310L + 301L)
* **Error_StudentGuide_XXXXXX.mlx**	<a LiveScript file that will guide you through the error analysis problem set and also help you pick up a few new MatLab skills.
* **problem1.xlsx**	<an excel file containing the data for problem 1, which you can use to import the data rather than typing it manually.>
## Module 4: Conjugated Dyes and PIB Module (CHEM310L + 301L)
* **dye_v4.mlx** 	< script for dye lab calculation of energies from particle in the box model, finds the optimum gamma value for a series of dyes, using the PIB model and experimental data.>
## Module 5: FTIR (CHEM310L + 301L)
* **FTIR_StudentGuide*** <script to test two different models to the experimental FTIR spectrum of HCl, and to calcuate molecular parameters from teh experimental data.>
* **example data** <this data is provided in case of instrument malfunction>
## Module 9: Apples Part I and II (CHEM301L only)
* **Apple_Template_Part1_*** 	< script for apples experiment part I - calculation of kinetic parameters for one variety of apple enzyme extract>
* **Apple_Template_Part2_*** 	< script for apples experiment part II - calculation of kinetic parameters for three concentrations of inhibitor>
